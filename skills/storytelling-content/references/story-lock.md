# Story Lock

## Contents

- Classification ledger

## Classification ledger

Record only fields relevant to the source.

| Class | Capture | Constraint |
|---|---|---|
| Event | what happened and did not happen | Do not add actions or combine separate incidents. |
| Sequence | known order and time gaps | Do not imply exact chronology when it is uncertain. |
| People | identity, role, relationship | Do not infer authority, intent, or consent. |
| Dialogue | exact quote, remembered wording, paraphrase | Use quotation marks only for supported exact wording. |
| Inner state | stated thought, feeling, motive | Attribute it or describe observable behavior. |
| Detail | time, place, object, physical or sensory fact | Do not invent cinematic texture. |
| Result | measured or observed outcome | Preserve scope, duration, and benchmark. |
| Relationship | sequence, association, claimed cause | Never increase causal strength. |
| Meaning | author's lesson or interpretation | Keep it attributed; do not turn it into a law. |
| Unknown | missing, disputed, reconstructed | Omit, qualify, or ask when essential. |

## Forbidden upgrades

- `dia diam` -> `dia malu dan merasa kalah`;
- `setelah kampanye, penjualan naik` -> `kampanye itu menaikkan penjualan`;
- remembered meaning -> a polished verbatim quote;
- `gue sering gagal` -> an invented count of failures;
- a composite lesson -> one fabricated scene;
- a partial improvement -> a triumphant permanent ending.

Compression is allowed only when it does not fuse people, events, time, or
causes in a misleading way. Disclose composites or reconstruction when used.

## Missing information

Ask a focused question only if the answer changes the core arc or truth status.
Otherwise choose one:

- remove the unsupported detail;
- write the uncertainty directly;
- use an attributed interpretation;
- insert a visible placeholder when the user wants an outline;
- retain the source's ambiguity.

## Integrity questions

1. Could every asserted event be pointed back to the source?
2. Are quotes and paraphrases visually distinguishable?
3. Did chronology quietly become causality?
4. Did observable behavior become a claimed inner state?
5. Does the ending preserve the actual degree of resolution?
6. Did tension or compression hide a material qualifier?
