# Information Release

## Contents

- Open loops
- Layered release
- Payoff
- Failure patterns

## Open loops

Create a precise unanswered question from a real contradiction, risk, choice,
or result. The source must contain the answer or an honest boundary. A vague
promise such as `yang terjadi selanjutnya bikin kaget` is not useful tension.

## Layered release

Reveal information in functional layers:

1. give enough context to understand the stakes;
2. show a consequence or clue;
3. delay one key answer while advancing the causal chain;
4. close the gap before introducing an unrelated claim.

Keep qualifications near the claims they limit. Never delay a qualification in
a way that makes the earlier wording false.

## Payoff

The payoff may be a result, mechanism, choice, reversal, limitation, or precise
lesson. It must answer the question created by the opening at equal or greater
specificity. If the source cannot repay the strongest opening, weaken the gap.

## Failure patterns

- opening with a dramatic consequence the body never explains;
- withholding basic context so the audience forms a false conclusion;
- repeating clues without advancing understanding;
- saving every useful detail for the final paragraph;
- ending with a generic lesson unrelated to the initial tension.
