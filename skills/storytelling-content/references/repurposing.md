# Repurposing Stories

## Contents

- Locked core
- Format changes
- Angle changes
- Integrity checks

## Locked core

Preserve events, sequence where material, people, evidence, transformation,
ending, and certainty. A new format or angle changes emphasis, not history.

## Format changes

- **Short video:** one tension, one causal chain, one payoff; add delivery notes
  only when requested.
- **Carousel:** one functional step per card; keep qualifiers on the same card as
  the claim they limit.
- **Caption/newsletter:** allow context and reflection without duplicating the
  same lesson.
- **Thread:** each post must advance event, consequence, or interpretation; do
  not manufacture mini-cliffhangers.

## Angle changes

Valid angles include lesson, failure, behind-the-scenes process, relationship,
decision, constraint, and audience relevance. Select only angles present in or
entailed by the locked story. Do not turn the same event into conflicting claims
about why it happened.

## Integrity checks

Compare every variant to the same lock. Flag a requested format that cannot fit
the necessary qualification or payoff instead of deleting them silently.
