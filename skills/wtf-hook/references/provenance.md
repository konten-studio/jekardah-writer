# Provenance and Design Influence

The hook framework was distilled from privately supplied educational material into the original, compact guidance in this skill's `framework.md`, `types.md`, and `examples.md`. The source document is not distributed. These references are sufficient to run the skill without access to that source.

The workflow structure also draws on the public Blotato `viral-hooks` skill documentation, fetched from <https://help.blotato.com/claude-skills/claude-skills/viral-hooks.md> on 2026-08-16. Adopted structural concepts are:

- select a category/type from the available angle;
- generate multiple concrete candidates rather than one first draft;
- stress-test openings and remove front-loaded filler;
- return a named winner plus useful alternatives.

This skill does not copy or bundle Blotato's 100-hook library. Its Indonesian calibration, factual safeguards, scoring gate, rewrite behavior, and composition contract are original adaptations created for this workflow.
